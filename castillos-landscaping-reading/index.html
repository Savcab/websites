A patio is only as good as the ground beneath it. So we build the ground first, then set the stone.

We’re a Reading-based design-build crew laying paver patios, walkways, stone steps, retaining walls, beds and privacy fence across Berks County. Every job starts as a small design question — how the stone meets the house, where the water needs to go, and how it will read once it has settled in.

Then we build it the slow way: excavation, a compacted base, the right grade for drainage, and every paver and stone set by hand. It’s the part no one photographs, and it’s why the work is still level and true a few winters on.

How we work

Design it, build it, leave the site clean.

A straightforward path from the first look at your yard to the day you start using it.

See the space

We come out, walk the yard, and talk through what you’re picturing — and how the stone, the grade and the drainage want to work together.

A clear estimate

You get a written estimate with materials, layout and price spelled out — no vague numbers and no surprise add-ons once we start.

Set on a real base

We excavate, compact the sub-base, set the grade so water drains, and lay every paver and stone by hand — the slow part, done right.

Cleaned and done

We finish the edges, clean the site down, and hand back a patio, wall or walkway that’s ready to use and built to stay put.
