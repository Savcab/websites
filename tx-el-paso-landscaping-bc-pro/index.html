El Paso code

Xeriscape isn’t just style here.

El Paso runs a mandatory, year‑round landscape watering schedule — every address gets specific watering days, with summer hours restricted from 10am to 6pm on those days. City code also requires new landscape designs to use mostly low‑water, drought‑tolerant plants. That’s the ground we design on every day: gravel, native and low‑water planting, and hardscape that works with the desert instead of against it.

Source: El Paso Water conservation ordinance & El Paso Code of Ordinances Ch. 18.46 · verified 2026‑08‑16
